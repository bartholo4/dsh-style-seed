# 开发与验证记录

这份记录概述项目的主要设计、实验和结果。测试数字只适用于所列版本、场景和样本，不等同于长期成功率或答案质量提升。原始私有会话、凭据、请求内容和实验日志不随仓库公开。

## 目标与最初的对照

项目起点是探索：对 DeepSeek Harness 的模型请求提供一段历史对话及思考样例，是否会让后续思考更接近自然、任务导向的英文表达。参考过已有工具中的行为及用户授权的样例；DSH 插件代码独立实现，没有复用该工具的运行代码。

最初比较了无样例和不同历史组织方式。早期对照并没有证明任意样例都有效。随后发现，不同兼容服务可能读取不同的历史思考字段；在一个固定模型和服务组合中，将历史 assistant 思考放入 `reasoning` 而非默认的 `reasoning_content` 后，观察到更符合目标的表达。服务端接受字段或计入 token，本身不能证明模型内部如何使用它。

## 会话开关与原生流程

早期独立 provider 版本需要显式选择插件提供的模型；之后项目转向与 DSH 会话集成：每个新会话独立控制、默认关闭，并保留用户原本的模型选择。开发中分别检查了会话状态、身份与引用校验、模型配置变化、首轮、续聊、工具调用、重启恢复、图片和配置错误等路径。

在一次较早的 `.5` Web 实验中，使用固定的 d1api DeepSeek 模型与相同的问题，进行 8 对新会话对照：开启样例时 8/8 个首响应以 “We need” 开头，关闭时为 3/8。当时使用的是较长的旧样例，并非仓库现在提供的缩短样例。该观察仅覆盖当时的实验版本和单一模型／服务组合；它记录的是措辞风格，没有构成答案质量的盲评，也不能证明当前短样例或其他模型会有相同变化。

## 样例缩短、内容影响与首轮策略

为减少额外上下文，开发过程中尝试缩短多轮样例的回答和思考片段，也比较了更短、更中性的候选。不同样例对风格的影响并不一致；有些中性候选没有达到既定风格目标。

测试同时发现，样例内容可能串入真实回答：在一次模糊自检中，模型把样例里的盒子题当成了真实对话。后续将新会话改为只在第一个成功答复前直接发送样例；这减少后续重复发送，但无法撤销样例对首答的影响，也不能保证续聊完全不受影响。

仓库提供的示例是经提供者审阅并同意公开的两轮内容；个人路径和内部来源记录已去除。样例的有效性依赖具体模型、服务和上下文，请独立判断是否适合自己的任务。

## 图片、超时与跟随所选模型

Web 试用曾因插件拒绝工具返回的图片而报错。后续加入用户图片和工具图片的处理，并通过合成宿主流程及两次真实合成图片请求进行有限验证；不同版本、最终代码和不同测试条件应分别看待。

请求总时限后来交回宿主和所选服务处理；当前跟随所选 provider 的版本不再自行设置此前的 120 秒总时限。各 provider、服务端或客户端仍可能设置自己的时限。

`0.2.0-experimental.13` 将新会话改为使用 DSH 当前选择的 provider、模型和请求参数，并针对 OpenAI Chat Completions 与 DSH 官方 DeepSeek Messages 实现样例映射。新会话的样例临时加入请求，不写入会话事件；较早版本的持久引用使用单独的兼容处理。

这一内部候选记录了 137 项合成检查，并进行了一次真实 d1api 合成算术请求：请求成功，样例思考字段到达出站请求，答案正确，单次思考以 “We need” 开头。其他服务地址、官方账号、真实用户原会话和桌面日常使用并未因此获得实网验证。公开仓库整理的是可移植测试子集，并非内部 137 项的原样复现；依赖旧实验源码的 `.12` 跨版本迁移等测试未包含。发布前公开回归集以 Node 24.19.0 和 DSH 0.2.2-alpha.2 运行时执行，123 项通过、0 项跳过。

## 发布前复核与仍存在的问题

发布准备中另外使用真实 DSH alpha.2 的部分宿主组件，配合纯内存合成数据和禁网替身，复现了运行中禁用／重载的并发问题：已认领但尚未写入的消息可能失败，或者普通 provider 在未携带样例时完成首答。旧版持久引用在插件移除后还可能作为普通文本标记进入请求。通过这些测试表示**缺陷已被复现**，不表示修复通过。

目前没有证明插件内部能原子阻止宿主在卸载窗口继续接收输入，因此本仓库按实验版公开。维护前应停止所有客户端提交、等待任务和队列结束并正常关闭服务；旧会话的迁移和回退仍需另行处理。参见主 README 的已知限制。

发布前另外使用官方 DSH 0.2.2-alpha.2 CLI，在全新隔离的 DSH home、profile 和包存储中离线执行本地目录安装；该安装为指向隔离源码快照的 `link:`。组合配置中识别了已启用组件和独立合成样例，Web 启动至就绪；没有进行浏览器、RPC 或模型对话的端到端验证，也未验证 tarball 安装。测试通过进程级网络守卫，未观察到连接尝试。
